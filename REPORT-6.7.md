# Отчёт по части 6.7: исправления по проверке

Ветка: `gemini/6.7-fixes` (от `gemini/6.6-gangs`).

## Исправления

1. **Рейд только для капитана финальной волны (`RaidBattle.java`, `Acts.java`, `ActsTest.java`)**:
   - В `RaidBattle` добавлен набор `FINAL_CAPTAINS` (заполняется при вызове капитана в `RaidBattle.tick`), а `RaidBattle.activeRaidFor(MobEntity)` возвращает `Raid` **только** если моб является капитаном финальной волны (`Acts.isFinalWaveCaptainMatch`).
   - Рядовые разбойники и мобы ранних волн больше не включают режим рейда (ранг 4, свита, `onWin` / `onLoss`).
   - Добавлен юнит-тест `ActsTest.raidModeAppliesOnlyToFinalWaveCaptain`.

2. **Урон по дракону и фаза при проигрыше (`Battle.java`, `DragonBattle.java`)**:
   - При победе над драконом, если `killer == null`, сначала берётся любой живой игрок-участник баттла; если живых игроков нет, используется `world.getDamageSources().badRespawnPoint(pos)` (входит в тег `ALWAYS_HURTS_ENDER_DRAGONS`), чтобы `damagePart` всегда засчитывался.
   - В `DragonBattle.onLoss` при проигрыше выставляется `PhaseType.HOLDING_PATTERN` вместо `PhaseType.TAKEOFF`.

3. **Плашка «ОТБЕЙ»: склеивание слов в мишенях (`Llm.java`, `ActsTest.java`)**:
   - Причиной было `.replaceAll("[^\\p{L}-]", "")`, которое удаляло пробелы между словами (`"лавовый компот"` → `"лавовыйкомпот"`).
   - Добавлен `Llm.cleanTarget(String raw)`, сохраняющий пробелы при очистке и выбирающий одно самое длинное значимое слово из фразы, чтобы ответка надёжно засчитывалась.
   - Добавлен юнит-тест `ActsTest.cleanTargetNeverGluesMultiWordTargets`.

## Проверка
- `gradlew build test --no-daemon` — `BUILD SUCCESSFUL` (все тесты, включая новые в `ActsTest`, пройдены).
- **Как проверить руками в игре**:
  1. **Рейд**: начни рейд, победи рядового разбойника в 1-й волне — рейд НЕ завершается и тотем не падает. Дойди до финальной волны и победи капитана со знаменем — рейд завершается победой с наградами.
  2. **Дракон**: победи дракона (в том числе при вышедшем MVP) — запускается ванильная смерть дракона; проиграй дракону — он переходит в `HOLDING_PATTERN`.
  3. **«ОТБЕЙ»**: на ходе игрока слова на плашке «ОТБЕЙ» отображаются раздельно, без склейки.
