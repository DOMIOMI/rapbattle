# Отчёт по части 6.1: Акт 1 — Окраина (ранги 1–2)

Ветка: `gemini/6.1-act1` (от `origin/main`).

## Реализация

1. **Самодельный микрофон (`homemade_mic.json`, `Trophies.java`, `MicModel.java`, `BroadcastHud.java`)**:
   - Рецепт `data/rapbattle/recipe/homemade_mic.json` (`. C . / . R . / . S .`) выдаёт `minecraft:lightning_rod` с `custom_name`, `custom_data {rapbattle_trophy: "homemade"}` и `lore`.
   - Книга рецептов (`data/rapbattle/advancement/recipes/homemade_mic.json`) открывает рецепт при первом получении медного слитка (`minecraft:copper_ingot`).
   - В `Trophies.TrophyPerk` добавлен `HOMEMADE`: работает только во второй руке, не даёт бонуса к урону/окну/стилю. В `MicModel` кнопка оранжевая (`ORANGE_TERRACOTTA`), без свечения.
   - В `BroadcastHud` на 4-й доле каждой строки игрока по краю таблицы рифм пробегает короткая белая рамка.

2. **Ночная охота (`Acts.java`, `Battle.java`)**:
   - В `Acts.isNightHuntDoubleLoot` и `Acts.applyNightHuntXp` вынесена чистая логика: ночью на рангах 1–2 против одиночного моба (`mobTeam.size() == 1`, без `overdressed`) выдаётся двойной лут, опыт ×1.5 и сообщение «Ночная охота: лут ×2». Днём на рангах 1–2 поведение прежнее.

3. **Подсказка про почерк (`Stats.java`, `Battle.java`, `PvpBattle.java`, `RapBattleClient.java`)**:
   - В `Stats.Player` добавлены флаги `hinted500` и `hinted1500` с дефолтом `false` в кодеке для совместимости со старыми мирами.
   - При первом пересечении 500 и 1500 Респекта игрок получает в чат сообщение с кликабельной кнопкой `[Выбрать почерк]`, выполняющей `/rapbattle style` и открывающей `StyleScreen`.

## Проверка
- `gradlew build test --no-daemon` — `BUILD SUCCESSFUL` (включая `ActsTest`).
- **Как проверить руками в игре**:
  1. **Крафт и перк**: возьми медный слиток (`/give @s copper_ingot`) — откроется рецепт в книге; скрафти Самодельный микрофон (медь сверху, редстоун по центру, палка снизу), переложи его во вторую руку (`F`), вызови зомби (`/summon zombie`, удар пустой рукой). От первого лица кнопка на микрофоне оранжевая (без свечения), на 4-й доле твоей строки по краю таблицы пробегает белая рамка.
  2. **Ночная охота**: `/time set night`, `/summon zombie`, победи одиночного зомби (ранг 1–2) — в чате «Ночная охота: лут ×2», лут удваивается, опыта ×1.5. Повтори днём (`/time set day`) — двойного лута и сообщения нет.
  3. **Подсказка почерка**: набери ≥ 500 (и ≥ 1500) Респекта в баттлах — в чат придёт одноразовое сообщение с кнопкой `[Выбрать почерк]`, клик открывает `StyleScreen`.
